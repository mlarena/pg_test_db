# Тестовая база данных участников клубов

Проект для создания и заполнения тестовой базы данных PostgreSQL с информацией об участниках спортивных клубов.

## Структура базы данных

### Основные таблицы:

- **regions** - справочник регионов (10 записей)
- **clubs** - справочник клубов (5 записей) 
- **organizations** - справочник организаций (5 записей)
- **club_members** - основная таблица участников (1 млн записей)

### Поля таблицы club_members:

- Основная информация: номер участника, ФИО, регион, клуб
- Организационные данные: организация, даты зачисления/выгрузки
- Статистика: количество часов, количество клубов
- Дополнительные поля: текстовые, булевы, временные метки

## Требования

- Python 3.7+
- PostgreSQL
- Библиотеки: `psycopg2`, `faker`

## Установка и запуск

1. Создайте базу данных PostgreSQL
2. Настройте параметры подключения в скрипте:
   ```python
   DB_HOST = 'localhost'
   DB_NAME = 'test_db' 
   DB_USER = 'postgres'
   DB_PASSWORD = '12345678'
   ```
3. Запустите SQL-скрипт для создания структуры таблиц
4. Выполните Python-скрипт для заполнения данными:
   ```bash
   python fill_data.py
   ```

## Особенности

- Генерация 1 миллиона реалистичных записей
- Пакетная вставка данных (по 1000 записей за раз)
- Русскоязычные данные (ФИО, названия организаций)
- Связи по внешним ключам между таблицами
- Разнообразные типы данных для тестирования

## Использование

База данных готова для тестирования производительности, отладки запросов и разработки приложений.
